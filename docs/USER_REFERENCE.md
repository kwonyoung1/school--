# School Office OS 사용 매뉴얼

시설업무, 물품 구입, 지출사업, 업체별 지급과 오늘 한 일을 관리합니다. 모든 날짜·시각 표시 기준은 한국시간입니다. 로그인 후 등록한 자료는 서버 DB에 저장됩니다. 새로고침과 재배포가 자료 초기화를 의미하지 않습니다.

## 대시보드

시설 진행/미완료, 지출사업, 품의/원인행위/지출결의 미완료, 지급 예정, 카드기한 임박·초과, 오늘 처리 건수를 확인합니다. 카드를 누르면 해당 업무 목록이 열립니다. 카드기한 경고는 초과 건을 먼저 표시합니다. 최근 업무를 눌러 상세 내용을 엽니다.

## 시설 작업계획

**시설 작업계획 > 작업계획 작성**에서 업무명을 입력하고 **자동 작성**을 누릅니다. 현재 상태·영향·조치의 세 항목이 생성됩니다. 작업명만 있어도 초안을 만들지만 현장 상태는 직접 확인해야 합니다. 입력한 현재 상태와 영향·조치가 있으면 문구에 반영합니다.

자동 작성 문구는 직접 수정할 수 있습니다. **다시 작성**은 현재 입력으로 새 문구를 만듭니다. **전체 복사**로 다른 문서에 붙여넣습니다. 저장한 최종 문구는 다음 같은 작업명에 추천합니다. **수정한 문구 템플릿 저장**으로 문구만 별도 보관할 수도 있습니다.

상태는 계획/진행 중/완료/보류/취소입니다. 상태를 바꾸고 **저장**을 눌러 서버에 반영합니다. 완료 상태를 고르면 오늘 날짜가 채워지며 실제 완료일로 정정할 수 있습니다. 목록 별표는 즐겨찾기입니다. **삭제**는 확인 후 목록에서 제외하고 변경 이력을 남깁니다.

## 시설관리물품

한 구입 업무에 **+ 물품 추가**로 여러 품목을 등록합니다. 수량은 양의 정수, 단가는 원화 정수입니다. 각 품목 합계와 전체 구입 합계가 계산됩니다. **용도 자동 생성**은 이전에 저장한 같은 품목 용도를 우선 사용하며, 없으면 무료 규칙 엔진이 초안을 만듭니다. 예: 락스 → 기숙사 세면장 및 샤워장 청소·위생관리용. 생성 문구가 실제 용도와 맞는지 확인한 후 저장하세요.

## 지출사업과 업체별 지급

**지출사업 관리 > 신규 사업 등록**에서 사업 기본정보를 입력합니다. 예산은 학교 자체예산/지원금/기타입니다. **+ 결제·지급 건 추가**를 눌러 업체를 등록합니다. 같은 업체를 여러 번 추가하거나 카드와 계좌이체를 섞어도 됩니다. 업체 이름을 입력하면 과거 업체명 추천 목록을 이용할 수 있습니다. 새 업체는 서버의 업체 목록에도 저장됩니다.

금액은 세 가지입니다.

- 품의 금액: 사업에 승인받은 금액
- 지급 예정금액: 업체별 배정할 금액
- 실제 지급금액: 실제 지급한 최종 금액. 미입력은 0원과 구분합니다.

업체 예정액 합계가 품의액보다 크면 **품의 금액 초과**, 작으면 **미배정 금액 있음**을 표시합니다. 금액 차이만으로 저장을 막지는 않습니다. 취소한 지급 건은 합계에서 제외하고 원래 값·이력을 보관합니다. 실제 합계, 지급 완료 금액, 미지급 잔액, 카드/이체 예정액도 확인하세요. 미지급 잔액은 완료/취소가 아닌 건의 `max(예정액−입력된 실제액, 0)` 합계이며 회계시스템과 자동 대사한 금액은 아닙니다.

사업의 **품의 완료**와 각 지급 건의 **원인행위 완료**, **지출결의 완료**, **지급 완료**는 별개입니다. 버튼을 눌러 값을 바꾼 뒤 **저장**합니다. 완료를 취소할 수도 있으며 변경 전후와 서버 저장 시각이 기록됩니다. **상세 날짜·비고 수정**에서 실제 처리일로 정정합니다. 서버 저장 시각과 업무 처리일은 다른 정보입니다.

**지급 완료**에는 실제 지급금액과 실제 대금 지급일이 필요합니다. 버튼은 날짜를 오늘로 채우지만 금액은 추정하지 않습니다. 카드 승인일은 실제 정산 지급일과 다릅니다. 지출결의를 완료해도 돈이 지급되었다고 자동 처리하지 않습니다. 원인행위·지출결의 `3/5건 완료` 표시는 취소를 제외한 지급 건을 기준으로 합니다.

**업체별 지급관리**에서 전체 사업의 지급 건을 함께 조회합니다. 사업/업체 검색, 예산·방식·지급상태·지출결의 미완료·임박 필터와 기간·정렬을 조합하세요. 기간은 지급 예정일이 있으면 그 날짜, 없으면 사업 품의일 기준입니다. 업체명을 누르면 해당 사업의 상세가 열립니다. 하단 업체별 집계의 업체명은 해당 이름으로 검색합니다.

## 카드기한

지급 건의 **처리기한**을 설정합니다. 지급 예정일과 별도입니다.

| 남은 기간 | 표시      |
| --------- | --------- |
| 8일 이상  | 정상      |
| 4~7일     | 주의      |
| 0~3일     | 긴급      |
| 어제 이전 | 기한 초과 |

지출결의와 실제 지급이 모두 완료되거나 지급 건이 취소되면 경고를 종료합니다. 지급 완료만 확인하고 지출결의가 남아 있으면 경고를 계속합니다. 날짜는 조회·렌더링 시 한국시간으로 다시 계산합니다. 장시간 열린 화면은 **새로고침**으로 최신 자료와 기한을 갱신합니다. 문자·푸시·이메일을 발송하지 않습니다.

## 오늘 한 일과 보고서

저장·수정·상태 변경·업체 추가/삭제·금액 변경·기한 변경 등 **서버에 반영된 행동**을 자동 기록합니다. 저장하지 않은 화면 조작은 활동 이력이 아닙니다. 금액 변경 전후와 업체 이름을 기록합니다. 같은 저장에서 여러 변경이 있으면 여러 활동이 생깁니다.

날짜를 선택하면 해당 한국시간 일자의 기록과 보고서가 열립니다. 자동 보고서를 편집하고 **보고서 저장**을 누르면 DB에 보관합니다. **보고서 다시 작성**은 현재 활동으로 초안을 다시 만들며 저장 전까지 서버의 보고서를 덮어쓰지 않습니다. **전체 복사**, **인쇄 / PDF 저장**을 제공합니다. PDF는 브라우저 인쇄 기능이며 외부 유료 서비스가 필요하지 않습니다.

## 검색·초안·반복 업무·Excel

**업무 통합검색**은 시설/물품/지출사업의 제목·물품명·업체명·비고를 함께 검색합니다. 각 관리대장에서도 검색·기간·상태·정렬·즐겨찾기를 사용할 수 있습니다. 시설/물품 기간은 예정일 또는 등록일, 사업 기간은 품의일 기준입니다.

편집 입력은 해당 브라우저의 초안으로 자동 보관합니다. 닫았다가 같은 업무를 열면 복구됩니다. **초안 버리기**로 지우며 서버 저장 성공 후에도 지워집니다. 초안은 그 기기에만 있고 서버 백업이나 다른 기기로 이동되지 않습니다. 공용 PC에서는 초안을 남기지 말고 본인 전용 브라우저를 사용하세요.

작업계획·물품 용도는 저장 시 기억합니다. 지출사업의 **반복 업무 템플릿 저장**은 입력 양식을 보관합니다. **통합 설정·백업**의 양식에서 새 사업을 만들면 지급 건 ID를 새로 만들고 원인행위·결의·실제 지급 상태·실제금액을 초기화합니다. 사업 품의일·품의 완료일·처리기한은 실제 새 업무에 맞게 확인하세요.

각 관리대장의 **Excel 다운로드**는 현재 필터에 해당하는 자료를 `.xlsx`로 만듭니다. 시설, 구입 품목별, 사업별, 업체 지급별, 카드기한별, 일별 활동을 각각 출력합니다. 업체별 파일에서는 사업·업체·결제방식·금액·처리단계가 별도 열입니다. Excel 파일은 업무 공유용이며 통합 백업 복원 파일을 대신하지 않습니다.

## 백업·삭제·복원

**통합 설정·백업 > 업무 백업 다운로드**로 모든 통합 자료와 활동 이력을 보관합니다. 복원은 현재 통합 자료를 교체하며 최근 7개 복원 전 스냅샷을 보관합니다. 복원 전후 모두 업무 내용을 확인하세요. 계정 비밀번호·세션은 백업에 포함하지 않습니다. 삭제한 자료의 이력이 남으므로 영구 개인정보 파기 기능으로 취급하지 마세요.

기존 지출 화면과 통합 화면의 자료·백업 형식은 다릅니다. 전환 주의사항과 복원 크기 제한은 [배포 안내 8~9절](CLOUDFLARE_TECHNICAL_REFERENCE.md)을 확인하세요.
